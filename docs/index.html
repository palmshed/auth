palmshed/auth

Authentication for Palmshed projects. A framework-agnostic core, server adapters, storage adapters, a browser client, and a hosted service.

Overview Getting started Configuration Client Server Storage API Migration Deployment Troubleshooting

What it is

palmshed/auth provides sign-up, sign-in, session management, password recovery, and role-based access control. The core engine is framework-agnostic. Adapters connect it to servers, databases, and browsers.

Two ways to use it:

  • Hosted service at palmshed-auth.vercel.app. Consume the API with @palmshed/auth-client. No server to run.
  • Embedded. Use the published packages to run auth inside your own server with your own database.
